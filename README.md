# Wplace 像素色彩转换器

把普通图片转换成 Wplace 像素画模板的小工具：选调色板 → 上传图片 → 调参数 → 选算法 → 导出。

纯前端单文件，**双击 `index.html` 就能用**，不需要服务器、不需要安装任何东西。

## 功能

| 步骤 | 说明 |
|---|---|
| 1. 选择调色板 | 内置 Wplace 的免费颜色 / 付费颜色两套色板，也可自定义 |
| 2. 上传图片 | 支持任意图片格式，浏览器本地读取，不上传服务器 |
| 3. 调整参数 | 控制像素化尺寸、颜色数量等 |
| 4. 选择算法 | 多种颜色匹配算法，决定原图颜色映射到色板的效果 |
| 5. 颜色选择与替换 | 查看图像颜色统计，把某个颜色批量替换成色板里的另一个颜色 |

导出：
- **下载当前效果图** —— 得到可以直接照着画的像素图
- **导出选区** —— 只导出框选区域

## 使用

1. 下载本仓库（`Code → Download ZIP`）或直接打开 GitHub Pages 地址
2. 打开 `index.html`
3. 按左边栏从上到下操作即可

所有处理都在浏览器本地完成，图片不会离开你的电脑。
